# Close-Agent Pilot Planner & ICFR Readiness Scorer

A single-page app in one file (`index.html`) with no dependencies. It's the companion tool for an edition of the LinkedIn newsletter **AI in Finance, Done Right**: **"Why Most CFOs Still Don't Trust AI in the Month-End Close—And What BlackLine's Verity AI Cohort Just Proved"**.

## Features
- **Tab 1, Pilot planner:** Enter monthly volumes for account reconciliations, accruals, matching exceptions and collections call prep. The tool applies BlackLine's vendor-reported early-adopter ceilings, discounts them with a realization slider (default 50%), and shows hours freed, annual value, FTE equivalent and the best first workflow to pilot.
- **Tab 2, ICFR readiness:** Six gates: posting controls or approval, an immutable log, independent adversarial testing, an agent registry, a bounded pilot with a parallel tie-out, and auditors engaged with reviewers trained. You get a readiness dial, the biggest gaps, and a vendor due-diligence memo you can copy.

The demo figures are made up. Everything runs in the browser and nothing is uploaded.
